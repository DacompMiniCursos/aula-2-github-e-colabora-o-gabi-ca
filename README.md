# 📌 Calculadora Matemática

## 📖 Descrição
Este projeto é uma calculadora simples desenvolvida em Python.
Ela permite ao usuário realizar operações matemáticas básicas
como soma, subtração, multiplicação e divisão através do terminal.

---

## ⚙️ Como instalar

1. Clone o repositório:
```bash
git clone https://github.com/DacompMiniCursos/aula-2-github-e-colabora-o-gabi-ca
```

---

## ▶️ Como usar

1. Execute o programa com:
```bash
python main.py
```
Depois, escolha a operação desejada no menu e informe os números.

Atualmente, a calculadora implementa apenas operações básicas:
- Soma

Expandir as funcionalidades do sistema para torná-lo mais completo e útil.

### ✅ Sugestões de implementação
Adicionar as seguintes operações:

- Potenciação (ex: 2^3)
- Raiz quadrada

### 💡 Benefícios

- Aumenta a utilidade para o usuário
- Enriquece o aprendizado de programação
